## 实际改动

新增 `site/js/teaching-model.js`，提供可独立导入的 `modelTeaching` 对象，完整覆盖课程注册表中 `module === "model"` 的 **21 门课程、83 章**。每门课均有连续开篇、可直接读懂的前置解释、逐章正文、收束与一手来源。原课程 ID、章节 ID 保持不变；正文改写没有修改全局阅读器或测试。后续截图检查还促成了下面记录的 Patch 图局部视觉修复。

正文共含 168 个段落块、37 张对照表、39 组原生 MathML、10 个边界说明和 5 张静态示意图；有 69 条就地前置解释。数量只用来核对覆盖，不作为教学有效性的证明。

主文不依赖打开实验才能成立。公式用于明确数量关系、更新规则与推导；表格用于同一对象的路径、时间、表示或算法对照；静态图仅保留空间或时间关系确实有帮助的位置。没有统一强制三问、固定页数、每章插图或每章交互。

## 这次修复的解释断点

1. **新名词与新对象混在一起。** 每课前置直接说明必需的物理量或数学对象。正文第一次使用时定义动作块、本体状态、先验／后验、循环状态空间模型、价值网络等；课程链接只承担继续补深的作用。
2. **公式有结果但没有对象身份。** MathML 配有符号、维度／单位与操作说明。线性状态统一采用 `S: K×V`、`q/k: K×1`、`v: V×1`、`o=Sᵀq`；三角推导把目标矩阵 V 和宽度 Vdim 分开，并补 `K_rowsᵀD` 接回块末状态。
3. **直接展示某一状态，误以为展示了完整过程。** 完整层旧图的默认状态只显示首次归一化，正文未拿它充当完整残差结构；改用两条残差公式和路径表。抽样旧图的过滤条件与正文累计区间不同，正文直接给出自身完整区间。
4. **生成步骤与物理时间相混。** VLA 显式区分网络前向、生成迭代和控制周期。Flow 变量 τ 与控制时间分别解释；视频帧号与扩散等级 s 分开。
5. **把实现优化直接扩张成任务收益。** 配对数、元素字节、调用数与实际时间分别说明；VLA 队列不断流、世界模型预测逼真、KL 小，都没有被等同于任务成功。
6. **只给前半段推导。** MLA 压缩给出同一数值下的直接点积与吸收点积；Delta 从旧预测、残差、写回接到块内系统与块末状态；动作归一化从编码走回解码；世界模型从实际观测起点走到无真实未来观测的想象。
7. **复述符号而不检查约定。** π₀ 早期正文的插值、目标与积分方向存在容易误抄的组合。课程采用噪声→数据的自洽 τ 方向，导数为 A−ε；同时明确官方 openpi 的 `t=1−τ`、目标 `ε−A`、负步长对应关系，没有混用两套约定。

## 静态图的固定条件

| 课程／章 | 固定条件 | 图的教学作用 |

### 截图检查后的 Patch 身份修复

在 `dbafce0` 的桌面和手机截图中，原图像素虽带 `owner-*` 类，但背景被更高优先级的矩阵默认样式覆盖，展开行也未带相同身份标记。图注中的颜色对应因而没有实际呈现。

修复限定在 `foundation-figures.js` 的视觉分块图分支，以及 `mechanism-course.css` 的 `.ff-patch-map` 作用域：当前 2×2 区域与展开行使用同一主题强调色、描边和反色文字；格内小坐标保持不透明。正文图注直接追踪 `[0,1,4,5]`。其他矩阵图及视觉投影分支的样式不变。定向核对 4×4／8×8 图像、Patch 0–3 的八种状态，原图四个高亮值与展开行四值一致；修复后的浅色与深色截图另由整站审计确认。

## 来源与核对重点

课程内保留直接来源链接；以下是一手核对的主要依据。论文的说明用于确定机制和边界，教学小数值由本项目自行构造，没有复用论文图表或声称复现论文性能。

- [Attention Is All You Need](https://arxiv.org/html/1706.03762v7)：注意力、前馈、残差的基本职责；正文明确自己的 Pre-Norm 变体。
- [Hugging Face Tokenizers pipeline](https://huggingface.co/docs/tokenizers/pipeline) 与 [生成接口](https://huggingface.co/docs/transformers/main_classes/text_generation)：分词、采样参数与停止语义。
- [DeepSeek-V2](https://arxiv.org/html/2405.04434v5)：联合潜在压缩、权重吸收和解耦位置分支。
- [DeltaNet](https://arxiv.org/abs/2406.06484) 与 [Gated Delta Networks](https://arxiv.org/html/2412.06464v1)：Delta 规则、门控、分块与三角依赖；正文取转置后的统一状态方向。
- [Mamba](https://arxiv.org/abs/2312.00752)：输入相关的选择机制；与固定标量递推示例严格区分。
- [ViT](https://arxiv.org/abs/2010.11929)、[LLaVA](https://arxiv.org/abs/2304.08485) 与 [TimeSformer](https://arxiv.org/abs/2102.05095)：图像块接口、跨模态投影、时空分解路线。
- [π₀](https://arxiv.org/html/2410.24164v1)、[openpi 官方实现](https://github.com/Physical-Intelligence/openpi/blob/main/src/openpi/models/pi0.py) 与 [Flow Matching](https://arxiv.org/abs/2210.02747)：条件动作生成、时间方向和数值积分。
- [ACT](https://arxiv.org/abs/2304.13705) 与 [Diffusion Policy](https://arxiv.org/abs/2303.04137)：动作分块、时间集成和迭代动作生成的家族区别。
- [LeRobot 动作表示](https://huggingface.co/docs/lerobot/main/action_representations)、[数据格式](https://huggingface.co/docs/lerobot/main/lerobot-dataset-v3) 与 [处理流程](https://huggingface.co/docs/lerobot/main/introduction_processors)：动作字段、窗口边界、预后处理接口。`main` 文档按本次复核日阅读，不声称永远固定。
- [ROS tf2](https://docs.ros.org/en/ros2_packages/rolling/api/tf2/generated/doxygen/html/classtf2_1_1Quaternion-members.html)：参考系关系随时间管理；本课二维变换独立推导。
- [DreamerV3](https://arxiv.org/html/2301.04104v2)：RSSM 的 h/z、条件分布、预测目标、停止梯度、free-bits 下界与想象学习。
- [DDPM](https://arxiv.org/abs/2006.11239) 与 [DiT](https://arxiv.org/abs/2212.09748)：加噪幅度、训练目标及 Transformer 去噪网络的层次区别。

## 尚未覆盖的高级边界

这些课程已覆盖各自注册章节，但不是所有模型论文和全部部署细节的替代品。尚未展开：完整多头 MLA 的所有权重布局与位置外推、完整门控分块训练反向、混合状态架构的所有变体、具身旋转与力控制接口、硬件动力学稳定性、完整 Dreamer 优化实现、具体视频扩散采样器与真实任务泛化。

本轮没有真实模型权重、GPU 性能测量、机器人执行或受试者学习效果实验。可确认的是内容与例子的覆盖、数学自洽和数据契约；不能据此宣称读者已经掌握全部知识，或声称某种方法在真实硬件上更快、更稳定。
