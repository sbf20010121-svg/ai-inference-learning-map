- 六个研究原型能力并入原节点：线性更新/Chunk、IR/Mask/融合、调度预算/KV/跨轮、Top-k/分桶/EP/合并、在线归一化、同步/异步动作队列。旧URL兼容跳转，首页没有第二套研究课入口。

- 手机按章节横向导航，当前章节自动进入可视范围；复杂图/时间轴在局部滚动。暗色图中保留身份色与文字对比。键盘切章后聚焦问题，操作参数后保留按钮焦点。

## 尚未解决的范围

这次完成默认课程组织、核心机制可视表达、整站兼容与交互实现。**没有完成每项技术所有子机制、逐函数真实源码/设备产物审计，也没有证明学习者已完整掌握。**

1. 编译器没有本机GPU生成的真实TTIR/TTGIR/LLVM/PTX/SASS链；示意不能当成实际优化Pass证据。调优与性能需要固定设备、版本、输入并真实测量。
2. Delta三角教学限定无门控、初态0；完整Gated WY、低精度、反向和全部状态布局仍需专门实现审计。模型没有把不同线性注意力/SSM归为同一公式。
3. 调度器没有复现生产抢占、草稿、多模态与全部异步分支；MoE没有实际通信后端或网络重叠实验；PD、队列、流水线时刻是声明假设下的构造。
4. Flow、RSSM和状态平面数值未加载已训练权重；没有机器人任务成功率或世界模型长滚动质量验证。真实动作对齐/聚合不是本教学队列的自动推论。
5. FP8/FP4字段页只解释浮点与整数表示的差异，未声称覆盖每种格式的精确编码；MLA只验证内容项恒等式。TMEM图不是MMA合法形状/布局/完整同步代码，也不预测B200周期。
6. 浏览器与数学测试证明这些明确列出的行为，不证明教学效果。后续反馈应落在具体章节/机制，继续补充可检验的推导与实现证据。
